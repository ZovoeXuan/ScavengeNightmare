## 零、先看这一句

4C 的自动化已经能证明「代码路径走过」：三关能连、全队确认门会等第二个人、四类占位音互相可分。
**它证明不了 A1 / A2 / A10 / A11。** 这四项必须由非开发者第二人现场跑一遍，否则 P0 只能写「待签」。

| 场次 | 覆盖 | 谁玩 | 时长 |
|---|---|---|---|
| 第 1 场 | **A1** 单人 3 关 + **A10** 单关计时 | 1 名真人（可以是你，但更推荐第二人） | 30–40 分钟 |
| 第 2 场 | **A2** 双人 3 关 | 2 名真人 | 30–40 分钟 |
| 第 3 场 | **A11** 真人体验 | 2–3 名真人 | ≥30 分钟 + 5 分钟访谈 |

## 一、开测前的六个硬条件

全部为「是」才开测，否则数据不可用：

1. **同一个包**：所有人用同一份 zip 解出来的包，不要一人一个新版（`Assembly-CSharp.dll` 的修改时间要一致）。
2. **网络通**：房主先自测一次双窗口互连，确认别人填的 IP 真能进。
3. **录屏在跑**：房主开 OBS 或 Win+G，**必须带麦克风**——「可归因共同笑」只能靠录音。
4. **语音在跑**：YY / Discord / QQ 语音同一频道。没有语音的笑点记录等于废纸。
5. **计时器**：手机秒表或录屏时间轴，用来记每一关的起止（A10 只认这个）。
6. **不引导**：开测前只讲键位与「抓/扔/推车/长按开门」，**不讲策略**（A11 要求「不看攻略」）。

### 2.2 启动参数（关键）

| 轮次 | 参数 | 含义 |

### 2.4 加入步骤

1. 房主开包 → 左上角点 **Host（服务器+客户端）**。
2. 房主把**虚拟局域网 IP**（ZeroTier / Radmin 形如 `10.147.x.x` 或 `26.x.x.x`）发到语音频道。
3. 朋友开包 → 地址框填这个 IP → 点 **Client**。
4. 全部进图、双方都能看到对方在动 → 再开始计时。

## 四、每场怎么跑

### 4.1 第 1 场 · A1 单人 + A10 计时（30–40 分钟）

1. 开局读码阶段：从安全屋拿初始 5000 余额，确认商店 8 件都在（截图）。
2. 长按出口 → **单人也会立即确认**（全队 = 1/1）。
3. 进入 `Night1` 第 1 关：目标过关额 **1800**。搬货 → 装车 → 推车 → 公秤长按 1.2s 提交。
4. 达标后回安全屋 → 买 1 件（建议 `flashlight` 或 `tool_belt`）→ **再进去贪一趟**（验 Q1/Q2：余额不掉）。
5. 重复到第 2 关（**2400**）、第 3 关（**2800**）。
6. 全程 **不许看攻略、不许有人提示哪件值钱**。

计时口径：

| 关 | 开始 | 结束 | 时长 | 判据 |
|---|---|---|---|---|
| 1 | 首次踏进 Night1 | 公秤提交成功且余额 ≥1800 | __ | 6–9 分钟†（带内记 CONCERNS） |
| 2 | 第 2 关出生 | 余额 ≥2400 | __ | 8–12 分钟 |
| 3 | 第 3 关出生 | 余额 ≥2800 | __ | 10–14 分钟 |

> † 计划口径是 6–9 / 8–12 / 10–14，**只记录不美化**；越界记 CONCERNS，不许改写数字。

### 4.2 第 2 场 · A2 双人 3 关（30–40 分钟）

1. 两人同进安全屋。
2. 出口长按：**一个人按满 1.2s 后门必须不开**，HUD 显示 `继续 1/2`；第二个人按满才推进。
3. 若一人松手或走出半径超过 2 秒，`1/2` 必须掉回 `0/2`（当场口头确认一次）。
4. 三关各轮一遍，记录每次 `x/2` 数字。
5. 中途不要有第三人加入。

### 4.3 第 3 场 · A11 真人体验（≥30 分钟 + 访谈）

1. 不给任务，直接玩满 30 分钟（可以跨关，可以重复进夜路）。
2. 允许他们失败、团灭（团灭会回安全屋，余额不变、关数回 1——这是设计，不是 bug）。
3. 30 分钟到点后**先别关游戏**，立刻做 5 分钟访谈（`Playtest_4C_Interview.md`）。
4. 访谈只照着模板念，**不许提示答案**。

## 五、判据逐条（照抄，别自由发挥）

### A1 · 单人连续 3 关

| 项 | 判据 | 证据 |
|---|---|---|
| 关数 | 单人连过 3 关，`legIndex` 到 3 | 录屏 + `session_*.csv` |
| 时长 | 30–40 分钟（含安全屋） | 录屏时间轴 |
| 稳定 | **0 崩溃**；掉出地图 / 卡死靠脱困救回 ≤1 次 | 录屏 + F6 标记 |
| 钱 | 余额单调不减；再贪一趟不掉账（Q1/Q2） | 截图前后 + CSV |

### A2 · 双人连续 3 关 + 全队确认

| 项 | 判据 | 证据 |
|---|---|---|
| 关数 | 双人连过 3 关，两人都到第 3 关 | 两端录屏（至少房主端） |
| 确认门 | 1/2 时不换关、2/2 才换关，**每关都成立** | 录屏 + HUD `x/2` |
| 掉 ready | 松手/离开 2s 内计数回退 | 录屏 |
| 稳定 | 0 崩溃；两人都无「瞬移回出生点」 | 录屏 |

### A10 · 单关时长

- 三关各记一次原始时长（含安全屋时间要区分开）。
- 中位数落在 8–12 分钟为达标；区间外 1 分钟内记 CONCERNS。
- **原始样本全列**，禁止只报中位数。

### A11 · 真人体验（只能人判）

| 项 | 判据 |
|---|---|
| 时长 | ≥30 分钟 |
| 攻略 | 全程无攻略、无提示 |
| 自主意外 | **≥3 个**（玩家自己搞出来的意外，不是脚本安排的） |
| 共同笑 | **≥2 次**可归因共同笑（同一时刻、两人都在笑，且能说出为什么） |
| 复玩 | **≥50%** 的人选「再走一关」 |

> AI 不参与 A11 判定；本文件只提供记录格式。数据由开发者代填 = **A11 直接 FAIL**（C6）。

## 六、数据落盘与归档

| 产物 | 位置 |
|---|---|
| CSV | 房主机器 `包目录/PlaytestLogs/session_YYYYMMDD_HHMMSS.csv` |
| 录屏 | 房主机器任意位置，改名 `4c_a1_solo.mp4` / `4c_a2_dual.mp4` / `4c_a11_free.mp4` |
| 访谈表 | `Docs/Playtest_4C_Interview.md` 的表格（手填或转 CSV） |
| 归档目录 | `D:\drlj\builds\shots\2026-11-XX\`（按场次建子目录） |

CSV 列含义沿用 D7（`seq,local_time,epoch_ms,elapsed_s,type,player,detail,x,y,z`）。4C 新增事件见下表（`type` 列）：

| type | 含义 | detail 示例 |
|---|---|---|
| `leg_start` | 进入新关 | `leg=2 scene=Night1 quota=2400` |
| `leg_end` | 本关达标（门解锁） | `leg=2 progress=2400 quota=2400` |
| `continue_vote` | 某人按满出口 | `leg=3 netId=.. count=2/2` |
| `run_end` | 一局结束（团灭或退出） | `reason=wipe leg=1 balance=..` |

> `elapsed_s` 是 A10 的唯一自动来源：`leg_end.elapsed_s − leg_start.elapsed_s`。

## 七、判定规则（写死，避免事后自我说服）

1. 任一场出现 **崩溃**：该场证据作废，修完重跑，不许「就当没发生」。
2. **一人就换关**（A2）：判 FAIL，回修，不许记「偶发」。
3. 访谈里出现开发者口述答案：**A11 FAIL**。
4. 「再走一关」<50%：**A11 FAIL**，回 17.1 重审，不许用「他们太累」解释。
5. 时长越界：记 CONCERNS，**不许改判据**。
6. 正式美术/音频未接入：记「已知缺口」，**不影响 A1/A2/A10/A11 判定**。

## 八、已知限制（别当成 bug 报）

| 现象 | 原因 | 处理 |
|---|---|---|
| 音效是「嘀」「咚」这类合成音 | 4C 只有四类占位音（轮 / 重物 / 碎裂 / 诅咒前兆） | 正常，正式素材后补 |
| 只有房主听得见推车轮声 | 轮声目前仅服务端播 | 已知取舍，正式素材阶段随客户端音效广播一起收 |
| 远程玩家手里的物件有 75–100ms 拖尾 | 服务端权威 + 插值 | 既定代价 |
| 只有房主机器生成 CSV | 记录器只在服务端写盘 | 正常 |
| 花瓶碎块是 4 个方块、3 秒消失 | D13 占位 | 正常 |
| 门 / 怪只有占位外观 | 美术后补 | 正常 |
| 团灭回到安全屋、关数回 1、余额不变 | 4B 设计 | 正常 |
