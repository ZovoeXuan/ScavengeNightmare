## 一、概念一页纸

### 一句话卖点（冻结）
**「带上你的死党，在一栋停电的废弃超市里，用最蹩脚的物理操作把值钱货搬出来——搬得越多，节目效果越炸。」**
（备用短版：1-4 人合作物理拾荒喜剧：搬的是货，笑的是人。）

### 目标玩家（冻结）
能接受轻度惊吓的开黑玩家：2-4 人朋友局、Steam PC；喜欢 REPO / 人类一败涂地 / 恐鬼症的朋友局模式；不在乎剧情与美术精致度，在乎「局均笑点」和「能一起喊叫」。

### 三层循环（冻结）
1. **动作层（秒级）**：抓 → 扔 → 跑（+ 拖/叠）——物理手感即乐趣
2. **一局层（10-20 分钟）**：进图 → 拾荒 → 被追 → 撤离 → 结算
3. **长线层（小时级）**：解锁设施 / 怪物 / 装备 / 角色皮肤（数字展示型，不做数值养成）

### 抓 / 扔 / 跑 手感关键词（冻结词条，D7 实测后可依证据修订）

| 动词 | 手感关键词 | 参数方向（落地） |
|---|---|---|
| 抓 | 有重量、黏手、会滑 | 质量表 + 抓握阻尼 + 临界滑落 |
| 扔 | 有力度、会砸、会滚 | 投掷力度曲线 + 物体摩擦 + 落点偏差 |
| 跑 | 笨重、会喘、会被拖累 | 负重影响速度 + 搬重物缓慢 + 呼吸感（待 D7 验证） |

**手感三原则（冻结）**
1. 物体永远有物理反应，禁止「磁吸式」搬运
2. 操作要「看起来笨、想起来聪明」——笨拙感来自物理，不来自故意反人类的输入
3. 一切手感参数进数据表，改表即生效

## 二、范围冻结清单

### 必须做（P0，砍任何一项都要重新开评审）
1. 4 人联机核心：Mirror + KCP + Steam 大厅（房主权威）
2. 物理抓 / 扔 / 跑三动词 + 20 种可交互拾荒物
3. 搬运摩擦事件表 ≥10 条（D6 先做前 5 条「可触发占位版」，规格见下）
4. 4 固定角色 + 每局随机 1 张缺点牌（冲突加权 + 补偿收益）
5. 1 张地图（废弃超市白盒→精修）+ 2 种怪物（追猎 / 陷阱）
6. 撤离结算 + 死亡惩罚（倒计时缩短 + 刷新提前，HUD 显性可归因）
7. 意外发生器（每局 ≥2 个可剪辑瞬间，含至少 1 个系统或社交类）
8. 恐怖 / 喜剧节奏工具（安静期 2-3 段 + 追逐爆发期 1-2 段）
9. 名场面回放位 + 一键截图（传播前置）
10. 单人可进入（怪物压力 -30% + 倒计时放宽，纯参数约 2h）
11. 基础大厅 / 结算 / HUD UI：大厅入口（D2）、结算界面（D16）、功能 HUD（D17）、定调美化（D32）
12. 微恐氛围：灯光 + 音效（D29 灯光 / D31 音效，绑定 M3 验收）
13. 3D 美术定调 + 商店页素材（D26 / D33，绑定 M3 验收）

### D6 摩擦事件前 5 条（冻结规格）

| # | 事件 | 触发条件 | 笑点机制 | 验收要点 |
|---|---|---|---|---|
| 1 | 窄门卡位 | 物体宽度 > 门洞余量，或搬重物过门 | 大力士最易卡，队友推屁股 | 可推、可脱手、不穿模 |
| 2 | 手滑砸脚 | 投掷 / 搬运中松手时机差 | 砸队友硬直 + 惨叫 | 有硬直反馈、可归因 |
| 3 | 滚动体 | 圆桶类物高惯性、难抓稳 | 追着桶跑的名场面 | 惯性真实、可被拦 |
| 4 | 夹手 | 门闭合时持有物在门缝 | 强制脱手 + 门夹音效 | 脱手、物体不消失 |
| 5 | 易碎 | 高价值物受撞击 | 贵重品碎成渣，全场哀嚎 | 价值归零、碎渣表现 |

**D6 交付口径（已拍板）**：D6 只做前 5 条「可触发占位版」，每条 1-1.5h；手感与表现打磨放 D10 与 D22；不做美术精修。D7 实测后再决定哪些升级为「重点打磨」。
