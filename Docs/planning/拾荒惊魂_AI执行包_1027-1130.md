# 《拾荒惊魂》AI 执行包（10.27–11.30 · 第一版可玩版全程）

> 用法：**每次给 AI 开新会话，先粘贴「全局项目上下文」**，再粘贴当天任务的提示词（含验收与提交要求）。每天结束时按「每日收尾检查」交接给第二天的 AI。日期已按 2026 年日历核对星期。

---

## 0. 全局项目上下文（每次新会话先粘贴）

【项目全局上下文】
- 项目：《拾荒惊魂》1-4 人合作物理拾荒微恐喜剧，Steam PC 买断制，无盈利压力，目标 2026-11-30 做出可玩版。
- 引擎：Unity 6.3 LTS（6000.3.27f1），URP，C#。禁止 HDRP、禁止 DOTS/ECS。
- 联机：Mirror + KcpTransport + Steamworks(Facepunch) 大厅；房主权威；物理物件快照 10Hz + 客户端插值；活跃物理物上限 40。
- 数据驱动：所有可调数值用 ScriptableObject/JSON，改表即生效，禁止硬编码常量。
- 架构：输入 → 角色控制器 → 物理交互 → 规则系统 → UI；回合状态由 GameManager 持有。
- 代码规范：模块化；每个系统自带验收用例；每天必须可构建；Git 提交粒度 = 每天一个任务，消息格式 "#D{天} {任务名}"。
- 美术风格：Stylized 低多边形、冷库绿 + 警报红微恐打光；模型用 AI 生成（混元3D）+ 人工修模。
- 明确不做：自建后端、反作弊、多语言（仅中文）、手柄适配、内置语音、创意工坊、完整剧情。
- 角色分工：Qoder/OpenCode = 程序；豆包 = 策划协作 / 美术 / 音频；我 = 决策 / 测试 / 验收。
