# 三款对标游戏 · 全地图+物资+怪物 完整拆解
全部基于官方实装内容与实测数据整理，每款游戏按「地图结构动线 → 风险收益分层 → 物资价值分布 → 怪物刷新规则 → 项目适配价值」统一结构呈现，可直接对接咱们废弃超市地图的设计。

---

## 一、Lethal Company（致命公司）：3种室内原型 + 多难度月球
### 核心底层逻辑
所有月球共享**3种室内建筑原型**，每局基于原型程序化生成房间布局；难度越高的月球，房间数越多、路径越深、物资价值越高、怪物池越危险，严格遵循「深度=价值=危险」的正相关。

### 1. 三种室内建筑原型（所有地图的骨架）
| 原型 | 结构特点 | 动线特征 | 代表月球 |
|---|---|---|---|
| **工厂 Factory** | 工业风长走廊+机房+大车间，通道宽敞，遮挡少 | 树状分支，主通道清晰，左手法则可遍历全图 | Experimentation、Assurance、March、Titan |
| **宅邸 Mansion** | 复古豪宅风，小房间多、走廊窄，家具遮挡密集，视野受限 | 回路更多，容易迷路，房间密度最高 | Rend、Dine、Artifice |
| **矿井 Mineshaft** | 垂直分层结构，靠电梯连接上下层，洞穴区域开阔但光线极差 | 垂直动线为主，侧路少，退路单一 | Offense、Vow、Adamance |

### 2. 分难度月球详解（按难度从低到高）
#### ① 新手级：Experimentation（免费）
- **地图结构**：固定工厂原型，8-12个房间，路径极短，主入口正对主通道，消防出口在左侧楼梯上
- **物资分布**：总价值低，单局8-12件废料，以低值小件为主（易拉罐、纸杯、小零件，10-30信用点）；室外偶见蜂箱、木箱
- **怪物池**：仅基础小怪——巨型蜘蛛、陷阱跳蚤、囤积虫，无高危精英怪；室外偶见沙虫、无眼狗
- **设计价值**：纯教学图，入口安全区大，怪物密度极低，让玩家先熟悉拾荒-撤离循环

#### ② 进阶级：Assurance（免费）
- **地图结构**：工厂原型，消防出口落差大但无坠落伤害，是全图最快撤离点
- **物资分布**：10-14件，中低值为主，平均单局收益约250信用点；高价值件概率低
- **怪物池**：蜘蛛、囤积虫、重击者、线圈头概率提升；无小丑盒、幽灵女孩等无解怪
- **设计价值**：新手进阶首选，消防出口快速撤离的设计，让玩家敢深入探索，容错率高

#### ③ 中级：Adamance（100信用点）
- **地图结构**：工厂为主，稀有矿井变体；矿井变体垂直三层，深处物资价值翻倍
- **物资分布**：12-16件，中高值占比提升，矿井深层有概率刷核心装置（单件100+）
- **怪物池**：花斑蜥、胡桃夹子、线圈头、重击者常驻；矿井变体有概率刷孢子蜥蜴
- **设计价值**：付费入门图，「深层高风险高收益」的分层感最强，玩家明显能感觉到越往里走越赚也越险

#### ④ 高阶：Rend（550信用点）/ Dine（600信用点）
- **地图结构**：98%概率为宅邸原型，房间多、走廊窄，遮挡极多；消防出口离飞船极远，退路漫长
- **物资分布**：16-22件，高价值件占比超40%，大量50-150信用点的贵重品；宅邸藏书室是全图loot密度最高区域
- **怪物池**：花斑蜥、线圈头、重击者、胡桃夹子常驻；高概率刷小丑盒、幽灵女孩、无眼狗
- **设计价值**：标准高阶图，「窄视野+多遮挡+远退路」三重压力叠加，逼玩家组队分工，单人深入几乎必死

#### ⑤ 顶级：Titan（700信用点）
- **地图结构**：81%工厂、19%宅邸，是全游戏最大的室内地图之一；实验室布局，中央区域开阔，分支房间极多
- **物资分布**：20-28件，全游戏平均价值最高，大量单件100+的贵重品，核心装置刷新率高
- **怪物池**：全游戏最密集，几乎所有室内怪都能刷到——花斑蜥几乎必刷，多只线圈头/重击者是常态，小丑盒、幽灵女孩、无眼狗、囤积虫、孢子蜥蜴高频出现
- **设计价值**：压力拉满的终局图，飞船离主入口近但消防出口极远，室外还要穿越森林守护者的死亡区，「快速深入拿完就跑」是唯一解法

#### ⑥ 巅峰：Artifice（1500信用点）
- **地图结构**：主宅邸变体，房间数最多、路径最复杂，是全游戏迷宫感最强的地图
- **物资分布**：22-30件，平均单件价值全游戏最高，大量稀有贵重品，单局满收益可达1500+
- **怪物池**：全怪物池开放，面具怪、管家、孢子蜥蜴等特殊怪高频刷新，精英怪密度远超Titan
- **设计价值**：纯高手向地图，迷宫结构+满配怪物池，考验团队配合和地图熟练度

### 3. 通用物资与怪物刷新规则
- **物资分层**：入口房间=低值垃圾、中途房间=中值常规品、最深处房间=高值大件/易碎品；高价值物资必然伴随高怪物密度
- **怪物刷新**：初始怪全部刷在中深层区域，开局不会堵门；随时间推移刷新频率加快，越晚越危险；击杀怪物会大幅推迟下一只刷新时间，鼓励绕路不硬刚
- **陷阱分布**：炮塔、地雷、蒸汽管道固定刷在窄门、拐角、高价值房间入口，卡点效果极强

### 对咱们项目的适配价值
1. **三层分层直接套用**：超市入口收银台（低值小件）→ 货架主通道（中值常规）→ 仓库/夹层（高值大件），1:1对应LC的深度分层
2. **双出入口设计**：正门主入口（安全但远）+ 后门消防出口（近高值区但危险），和咱们超市结构完全匹配
3. **难度梯度模板**：后续做第二、第三张图时，可直接按「房间数+怪物池+高值占比」三个维度拉升难度，不用从零调平衡
4. **卡点设计参考**：窄门、货架拐角、楼梯口放高危怪/陷阱，对应LC高价值区入口的卡点逻辑

## 二、R.E.P.O.：4张主题地图 + 模块化房间生成
### 核心底层逻辑
共4张固定主题地图，每局从专属房间模块池中随机拼接生成，主题风格稳定但布局永不重复；**每张图有独立的专属物资池**，怪物全图通用，难度由关卡等级决定，地图本身只影响地形难度。

### 1. 监工宅邸 Headman Manor
- **地图结构**：多层窄走廊迷宫，中央楼梯为核心枢纽，垂直三层（地面+上层+地下室），是全图最难认路的一张；走廊极窄、遮挡多，视野受限严重
- **专属物资池**：家居收藏类——瓶中船、诅咒娃娃、电视机、奖杯、油画、人体雕像，单价值区间500-4000
- **怪物分布特点**：
  - 走廊巡逻怪密度全游戏最高，怪物沿走廊来回巡逻，转角极易脸贴脸
  - 常驻：呕吐虫、重甲锤击怪、黑袍死神、地精、监工、窥视眼、隐形怪、精神师、青蛙厨师、蝴蝶结
  - 地下室精英怪密度翻倍，高概率刷高阶怪
- **难度来源**：迷路成本极高，窄走廊无法绕怪，遇到怪只能硬冲或回头跑，容错率极低

### 2. 麦克詹尼克站 McJannek Station
- **地图结构**：废弃北极科考站，主平台为核心枢纽，附带下层维修隧道；开阔区域多、视线长，但遮挡物少，无处可躲
- **专属物资池**：工业科研类——盆景树、笔记本电脑、黄色卷轴、火焰喷射器、锯子、丙烷罐、危险容器、录像带、科研站主机、服务器、吉他，单价值区间800-45000（重水最高45000）
- **怪物分布特点**：
  - 开阔区适合远程/高速怪，失聪类怪物（死神、重甲）优势大
  - 常驻：重甲锤击怪、黑袍死神、地精、监工、窥视眼、顶级掠食者、猎人、尖叫者、影子小孩、动物、精神师
  - 下层隧道狭窄，容易被伏击
- **难度来源**：开阔地无遮挡，被怪发现就很难甩掉；顶级掠食者等高速怪在长通道里几乎无解

### 3. 斯威夫特布鲁姆学院 Swiftbroom Academy
- **地图结构**：巫师学院主题，中央主走廊+两侧教室分支，附带地下图书馆/实验室；教室是独立小房间，可关门躲避，走廊视野长
- **专属物资池**：魔法奇幻类——封印之书、音乐盒、符文立方体、发光矿石、红药水、爱情药水、沙漏、宝剑、花瓶、扫帚摆件、巫师法杖、狮鹫雕像，单价值区间600-50000
- **怪物分布特点**：
  - 分支房间多，每个房间都可能藏怪，探索要逐个清点
  - 常驻：呕吐虫、蝴蝶结、黑袍、监工、窥视眼、顶级掠食者、小丑、猎人、影子小孩、隐形怪、精神师、青蛙厨师、动物
  - 图书馆/实验室是高值区，同时精英怪刷新率翻倍
- **难度来源**：房间多、清点累，容易被躲在教室里的怪偷袭；但可关门躲避，容错率比宅邸高

### 4. 人类艺术博物馆 Museum of Human Art
- **地图结构**：中央大厅长廊+两侧展厅分支，附带地下室储物区；长廊视野极远，展厅空间封闭
- **专属物资池**：艺术猎奇类——线雕艺术、牙齿、奶嘴、涂鸦雕像、新有机牛奶、婴儿头、 boombox、取款机、宝石、汉堡、便便雕像，风格搞怪猎奇，单价值区间700-52000
- **怪物分布特点**：
  - 中央长廊是死亡通道，无遮挡，怪物能从很远发现玩家
  - 常驻：爆炸骷髅、黑袍、监工、窥视眼、顶级掠食者、小丑、猎人、影子小孩
  - 地下室储物区物资最密集，怪也最多
- **难度来源**：长廊横穿风险极高，要么绕侧展厅慢慢摸，要么赌运气冲长廊；高价值品大多在长廊两侧的展厅里

### 5. 通用怪物刷新规则
- **危险等级（DL）分层**：怪物分DL1（低阶小怪）、DL2（中阶特色）、DL3（高阶精英）三档
- **随关卡等级缩放**：
  - 1-2关：1只DL1 + 1只DL3
  - 3-5关：1DL1 + 1DL2 + 1DL3
  - 6-8关：各2只，共6只
  - 11关以上：2DL1 + 3DL2 + 3DL3，共8只
- **开局安全期**：关卡等级越低，开局安全期越长（1级240-360秒），安全期内怪物不主动巡逻，玩家可安心搜刮浅层

### 对咱们项目的适配价值
1. **主题物资池设计**：咱们后续做第二张图（比如废弃工厂、废弃学校）时，可以参考「一张图一套专属物资」的设计，强化主题辨识度，而不是所有图共用一套货
2. **垂直三层节奏**：地面层（安全低值）→ 上层/夹层（中高值）→ 地下室（最高值），完全对应超市的一层→夹层→仓库节奏
3. **模块化房间生成**：固定外墙和主通道，内部房间/货架从模块池随机拼接，后续做地图变体、提升重玩价值时可以直接复用
4. **难度缩放机制**：怪物数量随关卡数增加，而不是单只怪加数值，玩家感受到的是「怪变多了」而不是「怪变秒人了」，体验更友好

## 三、ZONE L.O.S.T.：单张实验设施Demo图 + 任务驱动探索
### 说明
游戏目前处于Demo阶段，仅1张核心地图，玩法是「收集保险丝→启动自毁→逃离设施」，物资和探索完全围绕任务展开，核心价值在于**狭窄空间的视野遮挡设计、怪物感知参数、陷阱与环境互动**。

### 1. 地图结构与动线
- **整体架构**：废弃实验设施，线性主走廊+两侧分支房间+深处核心实验室，整体紧凑无开阔大空间，全程窄空间压迫感
- **动线逻辑**：入口走廊 → 中央枢纽 → 两侧实验间/储物间（分布着保险丝、道具） → 深处核心实验室（最终任务点）
- **视野设计**：大量储物柜、实验台、杂物堆做视线遮挡，拐角盲区极多，怪物很容易贴脸才被发现；门后、房间角落是天然伏击点

### 2. 物资与道具分布
- **任务核心物品**：3-4个保险丝，分散在不同房间的保险丝箱里，是通关必需品，没有任何价值属性，纯任务道具
- **辅助道具**：手电筒、医疗包、钥匙卡等，分布在房间台面、储物柜里，用于探索、开门、恢复状态
- **环境陷阱**：大量老鼠夹分布在地面、房间角落，踩中会造成伤害+硬直+巨大噪音，吸引全图怪物；是Demo里最主要的翻车点
- **价值设计**：没有「物资卖钱」的经济系统，全部物品都服务于「存活+完成任务」，探索目标非常明确

### 3. 怪物刷新与分布
| 怪物 | 分布位置 | 行为特点 |
|---|---|---|
| **普通巡逻怪** | 全图走廊、房间巡逻，中浅层居多 | 标准三档状态机：巡逻0.9m/s、警觉1m/s、追逐3.2m/s；视野12m，脱离视线4秒重置，丢失目标后跑到最后目击点搜索3秒 |
| **工程师精英 Engineer** | 深处核心实验室常驻，不会跑到浅层 | 追逐3m/s，视野12m；有1秒反应延迟，不会秒锁玩家；会开门、爬楼梯，不会卡地形 |
| **电锯精英（新增）** | 随机巡逻，中深层出现 | 高伤害近战，移动有明显电锯声，玩家可听声预判 |
| **环境小怪（老鼠等）** | 地面、杂物堆里 | 无致命伤害，主要制造噪音、干扰玩家注意力 |

### 4. 核心设计亮点
- **掩体即安全**：躲在桌子、实验台等掩体后面，怪物会直接丢失目标，不会穿墙透视，给玩家明确的反制手段
- **声音=危险**：跑步、碰倒东西、踩老鼠夹、开枪都会产生噪音，吸引附近怪物，安静走路是核心生存技巧

### 对咱们项目的适配价值
1. **货架遮挡直接复用**：超市货架天然就是视线遮挡物，拐角盲区、货架后藏怪的设计可以直接照搬，开发成本极低
2. **怪物数值模板**：巡逻/警觉/追逐三档速度、视野范围、丢失目标时间、搜索逻辑，数值打磨成熟，可以直接套用到咱们的基础巡逻怪上
3. **环境陷阱设计**：老鼠夹的「伤害+硬直+噪音引怪」三重效果，完美对应咱们的NoiseBus系统，可以参考设计超市里的掉落物、玻璃碎片等陷阱

## 四、三款共性总结 & 咱们超市地图落地清单
### 1. 三款通用的铁则
- **深度正相关**：离入口越远，物资越贵，怪越密，永远让玩家做「贪还是撤」的决策
- **出入口有主次**：主入口安全但远，侧出口近但危险，支持多人分工探索
- **开阔地=死亡区**：无遮挡的长通道=怪物容易发现玩家，高价值物资都在分支小房间/深处
- **时间加压**：随游戏进程，怪物刷新变快、威胁变大，倒逼玩家推进节奏

### 2. 直接落地到咱们超市地图的设计
| 模块 | 参考来源 | 具体方案 |
|---|---|---|
| 三层分层 | LC深度分层 + REPO垂直三层 | 入口收银台（低值小件）→ 货架主通道（中值常规）→ 仓库/夹层（高值大件） |
| 双出入口 | LC消防出口 | 正门主入口（安全但远）+ 后门侧出口（近仓库但门口刷怪多） |
| 卡点设计 | LC陷阱卡点 + ZONE门后伏击 | 1.2m窄门、楼梯口、货架拐角放怪/陷阱，高价值区入口必卡点 |
| 物资分布 | REPO主题物资池 | 超市专属物资池：食品、日用品、家电、贵重烟酒，分区摆放，越往里越贵 |
| 怪物分层 | LC深浅层怪物池 | 浅层只有基础巡逻怪，中深层加特色怪，最深处放精英怪，开局不堵门 |
| 环境陷阱 | ZONE老鼠夹 | 地面碎玻璃、掉落货架、倒塌商品，触发造成伤害+噪音引怪，对接NoiseBus |

### 3. 后续扩展参考
