# 手感参数表 v0（D5 · 2026-10-27）

> 效力：本表是 M1–M2 手感调参的基线。改数值请改资产，不要改代码。
> 判定口径：**参数不是调着好看，是为「局均笑点 ≥2 次」服务的**，每组方案必须能说清它放大哪一类笑点。

## 一、两层结构（为什么不全写进物件表）

```
物件物理档（PropPhysicsProfile）   描述「这个物件有多重、多滑」
        ×
手感方案（FeelScheme）             描述「这一版游戏的手感调性」
        ↓
玩家实际感受到的抓握 / 投掷 / 负重
```

分开的理由：换调性不用动 20 个物件的数据；D7 实测后微调单个物件也不会打翻整套调性。20 种物件在 D13 落地时，只需要写物件档。

## 四、每套方案适合制造什么笑点（D5 验收口径）

### 轻快 · 抢货互扯型
跟手快、扔得远、负重几乎不拖累。玩家愿意「多带一件」「边跑边甩」。
- 放大：抢同一件货互相拉扯、撤离前把货甩给队友、逃命时乱扔砸中同伴
- 风险：物件「不够重」，会削弱 D1 冻结的「重量感」；如果 D7 出现「搬东西不好笑了」就必须弃用

### 稳重 · 物理翻车型（推荐基线）
标准惯性，D1 一页纸里写的核心笑点都建立在它上面。
- 放大：窄门卡位、堆叠倒塌、楼梯滑落、手滑砸脚
- 风险：偏保守，主播可能觉得「不够放飞」

### 沉重 · 挣扎型身体喜剧
跟手滞后、扔不远、抱重物明显掉速，「一切都很费劲」。
- 放大：重物拖不动、下楼梯被货带着滚、两个人抬同一件互相拖累
- 风险：**最容易变成「操作恶心」而不是「好笑」**。D7 如果出现「玩家抱怨不是抱怨笑，是真抱怨」，直接降级

## 五、怎么切

- **运行时**：进游戏后按数字键 `1 / 2 / 3`，左下角显示当前方案与笑点侧重
- **自动化**：`ScavengeNightmare.exe -batchmode -d4test -feel=light|solid|heavy`
- 方案只影响本地手感，不通过网络同步（同局玩家可以各用各的）；如果要统一，后续在房间配置里加一个字段即可

## 六、实测对比（同一用例 `-d4test`，仅换方案）

```
light  投掷 4.14 m/s（期望 4.14）· 跟手 1.71m · 撞墙 closestSide=-0.40 未穿模
solid  投掷 3.18 m/s（期望 3.18）· 跟手 1.70m · 撞墙 closestSide=-0.40 未穿模
heavy  投掷 1.92 m/s（期望 1.91）· 跟手 1.85m · 撞墙 closestSide=-0.40 未穿模
```

投掷速度严格等于 `冲量 × 方案倍率 ÷ 质量`，三档分别落在 1.30× / 1.00× / 0.60×。说明方案层是真实生效的，不是改了个 UI 文案。

## 七、D7 需要验证的假设（现在都还是纸面假设）

1. 「轻快」是否真的让抢货更好笑，还是只是让物理变得廉价
2. 「沉重」的边界在哪：0.6 倍是否已经越过「好笑」进入「恶心」
3. 圆桶 22kg 是不是最优的「难搬但能搬」档位，雕像 42kg 是否该改成「完全搬不动、只能拖」
4. 负重分母（100/70/45）与玩家速度的耦合是否合理：目前雕像在稳重与沉重下都触到 0.45 下限，意味着两个方案抱雕像一样慢，可能削弱差异
5. 移动参数表 `PlayerMove.asset`（走 3.2 / 跑 5.0 / 加速 24）是否需要跟方案联动

## 十、真人实测结论（2026-10-27 · 主方案已定）

| 问题 | 回答 | 判读 |
|---|---|---|
| 哪套最爽 | **轻快 light** | 主方案定为轻快 |
| 罐头 vs 雕像的重量差 | 明显 | 质量模型打穿了，轻快没有把重量感洗掉 |
| 沉重是「好笑」还是「恶心」 | 好笑 | 0.6 倍未越过红线，保留为可选方案 |
| 最别扭的地方 | 无明显 | 现有参数没有硬伤 |

### 三条影响决策的推论

1. **D1 的「重量感」没有被轻快牺牲** —— 本轮最重要的信号。轻快把投掷拉到 ×1.30、抓握拉到 ×1.50，但重量差仍「明显」，说明差异主要由**质量与摩擦**承载，不靠拖沓感硬撑。这意味着以后可以继续加快节奏而不丢核心卖点。
2. **D7 对照组用沉重，不用稳重** —— 既然轻快是基线、沉重被判「好笑」，两极对比的信息量远大于「轻快 vs 稳重」（稳重是中间值，容易测不出差别）。
3. **沉重不恶心，说明 D1 的「看起来笨、想起来聪明」原则成立** —— 笨拙来自物理而不是反人类输入，所以 0.6 倍给人的是「费劲」而非「操作恶心」。

### 仍然待验证（搬去 D7）

- 「最爽」是单人体验；朋友局的判据是**笑点密度**，不是爽度。轻快可能让节奏变快但笑点变稀，必须用「局均笑点 ≥2」核验。
- 沉重单人读作「好笑」，四人局可能变成「互相拖累到烦」，需在 D7 观察。
