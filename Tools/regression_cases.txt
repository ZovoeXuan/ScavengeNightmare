# Full regression case list: Sprint 4A + Sprint 4B
#
# Format:  <case>|<args>|<required success marker>|<note>
#   - Lines starting with # or blank lines are skipped.
#   - passes / expected are derived from the number of case lines here.
#     Never hardcode the count in the .bat: a deleted case must turn the run red.
#   - The marker must be the single terminal line of that case (S4A_*_OK / S4B_*_OK).
#   - ASCII only. cmd reads manifests in the OEM codepage; UTF-8 Chinese turns
#     into garbage that can contain command separators and silently drop cases.
#
# expected_min is a FLOOR, not an exact count: adding a case never requires
# editing it, but losing rows does trip it. It exists because cmd's "for /f"
# silently drops a final line that has no trailing newline - a lost CRLF makes
# the last case vanish, and without a floor the run still prints a clean
# "OK passes=22 expected=22". Adding cases may raise it in the same commit
# (S4B-5 raised it 23 -> 27); deliberately REMOVING cases must lower it in
# the same commit.
#
# expected_min: 27
#
# Ordering rule: s4bdownhost must be immediately followed by s4bdownclient.
# That pair is ONE acceptance case that needs TWO processes running at once
# (host listens, client connects to it). run_regression.bat launches the host
# detached on the host row and drives it from the client row.
#
